# Security Policy

## Supported Versions

Only the latest release is supported with security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/gboquizosanchez/filament-scroll-to-top/security/advisories/new) instead of opening a public issue.

You can also email germanboquizosanchez@gmail.com. Please include steps to reproduce and expected impact. We aim to respond within 5 business days.
